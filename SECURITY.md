## Reporting a Vulnerability

If you discover a security issue or secret leak detection bypass in EnvShield, please notify us immediately by emailing **[raghavjatin245@gmail.com](mailto:raghavjatin245@gmail.com)**.

Please include:
1. Vulnerability description and steps to reproduce.
2. Sample environment configuration triggering the issue.
3. Impact and severity assessment.
