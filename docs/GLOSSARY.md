# Technical Glossary — EnvShield

Key architectural terms and concepts utilized within **EnvShield**:

- **AST (Abstract Syntax Tree):** Hierarchical syntactic representation of parsed input.
- **Zero-Dependency Runtime:** Direct execution on Node.js core modules without external packages.
- **Bento Grid Layout:** Modular, asymmetric UI card structure designed for high data density.
- **Cybercore Aesthetic:** Terminal-inspired monospace typography paired with dark obsidian palettes and glowing accents.
